# Личный VPN на WireGuard

Свой VPN для себя: один небольшой сервер (VPS) + приложение WireGuard на ваших устройствах.
Весь трафик устройства идёт через сервер, провайдер и публичные Wi-Fi видят только зашифрованный поток.

В репозитории:

| Файл | Назначение |
|---|---|
| `server/install.sh` | Ставит и настраивает WireGuard на сервере за одну команду |
| `server/vpn-client.sh` | Команда `vpn-client`: добавить / показать / удалить устройство |
| `tests/test_client.sh` | Тесты скриптов (без root и без реального сервера) |

## Что понадобится

- **VPS** с Ubuntu 22.04/24.04 или Debian 12, виртуализация KVM (не OpenVZ/LXC), публичный IPv4.
  Самый дешёвый тариф подойдёт (1 vCPU, 512 МБ–1 ГБ RAM): обычно **около $4–6 в месяц**, актуальную цену смотрите у выбранного хостера.
- Локация сервера — страна, из которой вы хотите «выходить» в интернет. Чем ближе к вам, тем ниже задержка.
- Проверьте правила хостера: часть провайдеров запрещает VPN/прокси в условиях использования.
- Больше ничего: домен и платные подписки не нужны.

## Установка (5 минут)

На сервере под root:

```bash
apt-get update && apt-get install -y git
git clone -b claude/vpn-development-analysis-794l5s https://github.com/yaricsemenchuk/vpn.git
cd vpn/server
sudo FIRST_CLIENT=phone bash install.sh
```

Скрипт поставит пакеты, включит маршрутизацию, сгенерирует ключи, поднимет `wg-quick@wg0` (автозапуск после перезагрузки)
и сразу покажет QR-код для устройства `phone`.

Если у хостера есть облачный файрвол (в панели управления), откройте в нём **UDP 51820**.

Необязательные параметры (переменные окружения перед `bash install.sh`):

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `WG_PORT` | `51820` | UDP-порт сервера |
| `WG_NET_PREFIX` | `10.8.0` | внутренняя подсеть `/24` |
| `WG_DNS` | `1.1.1.1, 9.9.9.9` | DNS для клиентов |
| `WG_ENDPOINT` | определяется сам | публичный IP сервера |
| `FIRST_CLIENT` | — | сразу создать клиента с этим именем |

## Подключение устройств

1. Установите приложение **WireGuard** (iOS, Android, Windows, macOS, Linux — официальные клиенты).
2. На сервере: `sudo vpn-client add имя` (например `iphone`, `laptop`) — появится QR-код.
3. В приложении: «Добавить туннель» → «Сканировать QR-код». Включите туннель.

Для ноутбука без камеры: `sudo vpn-client show laptop`, скопируйте конфиг в файл `laptop.conf` и импортируйте его в приложение.

```bash
sudo vpn-client add NAME      # создать устройство и показать QR
sudo vpn-client show NAME     # показать конфиг и QR ещё раз
sudo vpn-client list          # устройства и время последнего подключения
sudo vpn-client remove NAME   # потерян телефон — отозвать доступ
```

Для каждого устройства создаётся свой ключ, поэтому один клиент можно отозвать, не трогая остальные.

## Как проверить, что всё работает

Включите туннель и откройте https://ifconfig.me — должен показаться IP вашего сервера.
На https://dnsleaktest.com не должно быть DNS вашего обычного провайдера. IPv6 внутри туннеля намеренно
не используется (весь IPv6-трафик клиента заворачивается в туннель и там блокируется), поэтому утечки по IPv6 нет.

## Безопасность

- QR-код и `.conf` клиента **содержат приватный ключ** — не отправляйте скриншоты, не публикуйте в чатах.
- Входите на сервер по SSH-ключу и отключите вход по паролю (`PasswordAuthentication no` в `/etc/ssh/sshd_config`).
- Включите автообновления: `apt-get install -y unattended-upgrades`.
- Делайте резервную копию `/etc/wireguard` (иначе после переустановки придётся заново выдавать все ключи).
- Сервер видит ваш трафик так же, как раньше видел провайдер. VPN переносит доверие к вашему провайдеру на хостера: «no-logs» тут обеспечиваете вы сами, не включая логирование.

## Ограничения

- **WireGuard легко распознаётся глубокой инспекцией трафика (DPI) и в ряде стран блокируется или замедляется**
  (например, Россия, Китай, Иран). Если туннель включается, но трафика нет, сначала попробуйте другой порт
  (`WG_PORT=443` — но он должен быть свободен), а если не помогает — нужен другой протокол с маскировкой под HTTPS
  (VLESS + Reality). Он в этом репозитории пока не реализован.
- Один сервер = одна страна выхода. Для нескольких стран нужно несколько VPS.
- Скорость ограничена каналом и трафиком тарифа VPS (проверьте лимит у хостера).

## Тесты

```bash
sudo apt-get install -y wireguard-tools qrencode shellcheck
bash tests/test_client.sh
shellcheck server/*.sh tests/*.sh
```

Тесты проверяют генерацию серверного конфига, выдачу адресов, согласованность ключей, права на файлы, удаление клиентов
и валидацию имён. `install.sh` целиком (пакеты, systemd, сеть) нужно запускать только на реальном сервере.
